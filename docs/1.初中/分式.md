# 分式

## 1. 分式及其性质

### 1.1 概念

如果 $A,B$ 表示两个整式，并且 $B$ 中含有字母，那么 $\dfrac{A}{B}$ 叫做**分式**。$A$ 是分子，$B$ 是分母。

- 分式有意义 $\Leftrightarrow B\neq 0$；
- 分式值为 $0$ $\Leftrightarrow A=0$ 且 $B\neq 0$；
- 当 $A=B\neq 0$ 时，分式值为 $1$；当 $A=-B\neq 0$ 时，分式值为 $-1$；
- $\dfrac{A}{B}>0$ 时 $A,B$ 同号；$\dfrac{A}{B}<0$ 时 $A,B$ 异号。

### 1.2 基本性质

$$\frac{A}{B}=\frac{A\cdot M}{B\cdot M}=\frac{A\div M}{B\div M}\quad（M\neq 0).$$

同乘或同除一个不等于 $0$ 的整式，分式的值不变。

### 1.3 约分与通分

- **约分：** 约去分子与分母的公因式。分子与分母没有公因式的分式叫做**最简分式**。
- **通分：** 把几个异分母分式化成同分母分式。
- **最简公分母：** 各分母系数的最小公倍数，与所有字母（或多项式）因式最高次幂的积。

确定最简公分母：先分解各分母，再取“系数最小公倍数 + 相同因式最高次 + 不同因式全保留”。

## 2. 分式的运算

### 2.1 加减法

$$\frac{a}{c}\pm\frac{b}{c}=\frac{a\pm b}{c},$$

$$\frac{a}{b}\pm\frac{c}{d}=\frac{ad\pm bc}{bd}.$$

分子是多项式时，加减前先加括号。

### 2.2 乘除法与乘方

$$\frac{a}{b}\cdot\frac{c}{d}=\frac{ac}{bd},\qquad \frac{a}{b}\div\frac{c}{d}=\frac{a}{b}\cdot\frac{d}{c}=\frac{ad}{bc}\ (c\neq 0),$$

$$\left(\frac{a}{b}\right)^n=\frac{a^n}{b^n}\quad（n为正整数,\ b\neq 0).$$

### 2.3 混合运算顺序

先乘方，再乘除，最后加减；有括号先算括号；同级运算从左到右。结果一般化为最简分式，并注明字母取值使原式有意义。

## 3. 典型例题

### 例 1：有意义条件

分式 $\dfrac{1}{a-1}$ 有意义 $\Leftrightarrow a\neq 1$。

分式 $\dfrac{1}{x+1}\div\dfrac{x-3}{x-2}$ 有意义时，需

$$x+1\neq 0,\quad x-2\neq 0,\quad x-3\neq 0,$$

即 $x\neq -1$ 且 $x\neq 2$ 且 $x\neq 3$（除式分子也不能为 $0$，否则除式无意义）。

### 例 2：值为 $0$

$\dfrac{x-2}{x+3}=0\Leftrightarrow x-2=0$ 且 $x+3\neq 0$，故 $x=2$。

### 例 3：通分运算

$$\frac{1}{x}+\frac{1}{x+1}=\frac{x+1+x}{x(x+1)}=\frac{2x+1}{x(x+1)}\quad（x\neq 0,\ x\neq -1).$$

---

## 4. 小结

分式问题先看分母（有意义、值为 $0$），再谈运算。约分通分务必先因式分解；混合运算结果要最简并注明限制条件。
