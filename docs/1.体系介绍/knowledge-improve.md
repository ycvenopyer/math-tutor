# 中学数学培优提高

> 本文档在苏科版/苏教版课内基础之上，整理培优、拔高、竞赛入门及特长生常见考查方向所涉及的知识与专题。  
> 培优内容面向全国主流体系，与江苏教材进度大体同步；江苏重点高中特长生、英才计划等选拔，通常要求课内扎实 + 综合拓展 + 部分竞赛初步知识。

---

## 培优层次概览

| 层次 | 定位 | 典型资源 |
|------|------|----------|
| 课内拔高 | 同步教材，难度略高于课本，侧重思维与方法 | 《探究应用新思维》、同步培优讲义 |
| 综合拓展 | 压轴题、模型化、跨章节综合 | 《数学培优新方法》、几何模型专题、万唯/学而思培优 |
| 竞赛入门 | 初中竞赛大纲补充内容，技巧性强 | 《数学奥林匹克小丛书·初中版》、希望杯/华杯赛题型 |
| 竞赛进阶 | 联赛一试、二试四模块 | 《奥数教程》《培优教程》《奥赛经典》 |

难度递进（黄东坡系列）：新思维 → 新方法 → 大视野（≈ 小蓝本难度，与课内同步）。

## 1. 初中阶段

### 1.1 代数培优

#### 数与式

| 专题 | 内容要点 |
|------|----------|
| 有理数进阶 | 绝对值化简、零点分段法、数轴动点、周期循环规律 |
| 找规律求和 | 裂项相消、错位相减、倒序相加、分组求和 |
| 整式运算 | 乘法公式变形、配方法、整体代入、拆项添项 |
| 因式分解进阶 | 十字相乘、双十字、试根法、主元法、待定系数法、换元法、当 a+b+c=0 时的分解 |
| 分式与根式 | 构造分式、条件化简（差异分析）、双重二次根式、有理化 |
| 实数 | 估算无理数、与数轴/几何结合 |

#### 方程与不等式

| 专题 | 内容要点 |
|------|----------|
| 含参方程 | 分类讨论、解的讨论、整数解/正整数解 |
| 方程组技巧 | 系数轮换式、整体换元、对称式方程组 |
| 不等式 | 含参不等式、整数解问题、绝对值不等式 |
| 一元二次方程拔高 | 求根公式推导、判别式深层应用、韦达定理变形、构造方程 |
| 特殊方程 | 可化为一元二次的高次方程、无理方程、二元二次方程组 |
| 不定方程 | 一次不定方程（裴蜀定理）、简单整数解问题 |
| 应用题建模 | 行程、工程、浓度、增长率、方案设计 |

#### 函数

| 专题 | 内容要点 |
|------|----------|
| 一次函数 | 与几何综合（面积、等腰、直角）、与方程/不等式联动 |
| 反比例函数 | k 的几何意义、与相似/特殊图形结合 |
| 二次函数 | 区间最值、含参图象、与一元二次方程/不等式综合 |
| 代数最值 | 配方法、均值不等式初步、几何法求代数最值 |
| 函数图象 | 图象变换、分段函数、动点与函数图象 |

### 1.2 几何培优：基础模型

与苏科版章节对应，培优阶段强调「识别模型 → 构造辅助线 → 证明/计算」。

#### 七年级相关

| 模型 | 适用场景 |
|------|----------|
| 双中点模型 | 线段中点、中点坐标 |
| 双角平分线模型 | 角平分线夹角、内角/外角 |
| 猪蹄/铅笔/锯齿模型 | 平行线间拐点、多折线角度 |
| 8 字/A 字/飞镖模型 | 三角形内角、外角关系 |
| 数形结合 | 坐标平面上的直线、中点坐标公式、距离公式 |

#### 八年级相关

| 模型 | 适用场景 |
|------|----------|
| 倍长中线 | 全等构造 |
| 截长补短 | 线段和差证明 |
| 角平分线模型 | 角平分线性质、辅助线 |
| 三垂直/K 型 | 全等或相似构造 |
| 手拉手/共顶点 | 旋转全等 |
| 半角模型 | 正方形/等腰直角三角形 |
| 弦图/赵爽弦图 | 勾股定理证明与应用 |
| 一线三等角 | 相似判定 |
| A 字/8 字/母子形/旋转型相似 | 比例线段 |
| 12345 模型 | 特殊角度（选填压轴常用） |

#### 九年级相关

| 模型 | 适用场景 |
|------|----------|
| 四点共圆/辅助圆 | 角相等、圆中角 |
| 定弦定角/隐圆 | 动点轨迹为圆弧 |
| 圆幂定理 | 相交弦、切割线 |
| 托勒密定理 | 圆内接四边形 |
| 阿基米德折弦定理 | 圆中弦与弧 |
| 垂径/圆周角综合 | 圆的基本计算与证明 |
| 三角形四心 | 重心、外心、内心、垂心 |
| 解直角三角形模型 | 仰角俯角、坡度、面积 |

### 1.3 几何培优：最值与动点

江苏培优与压轴题中高频，常跨轴对称、相似、圆、二次函数。

| 专题 | 核心思想 |
|------|----------|
| 将军饮马 | 轴对称转化，两点之间线段最短 |
| 将军饮马变式 | 两定一动、两动一定、平移型、多个动点 |
| 费马点/加权费马点 | 120° 夹角、旋转构造 |
| 胡不归 | 加权路径 PA+k·PB，构造 30° 直角三角形 |
| 阿氏圆 | 到两定点距离比为定值的轨迹 |
| 瓜豆原理/主从联动 | 动点轨迹（直线/圆弧），从动点最值 |
| 逆等线 | 线段转化与最值 |
| 隐圆八大类 | 定角对定弦、对角互补、定角定边等 |
| 几何最值函数化 | 设参建立函数，二次函数/三角函数求最值 |
| 面积最值 | 割补、相似比、坐标法 |
| 存在性问题 | 等腰/直角/平行四边形/相似/相切等条件下动点存在 |

### 1.4 代几综合

| 专题 | 内容要点 |
|------|----------|
| 一次函数 + 几何 | 直线与坐标轴、三角形面积、全等/相似 |
| 反比例 + 几何 | 双曲线与特殊点、矩形/菱形存在 |
| 二次函数 + 几何 | 抛物线与直线交点、线段/面积最值、含参讨论 |
| 二次函数存在性 | 定点/定值、等腰/直角/平行四边形、相似、相切 |
| 圆 + 坐标系 | 动点相切、圆与抛物线、解析化几何 |
| 旋转/折叠综合 | 坐标变换、对应点关系 |
| 新定义问题 | 距离、变换、运算的新定义阅读理解 |

黄东坡《培优新方法·九年级》综合板块示例：抛物线与特殊三角形/四边形/面积；圆与直角坐标系中的相切。

### 1.5 竞赛拓展（初中竞赛大纲补充）

课内不系统讲授、培优/竞赛入门需补充的内容。

#### 数论初步

- 整除性判定（2、3、4、5、8、9、11 等）
- 质数与合数、算术基本定理
- 最大公约数与最小公倍数、辗转相除
- 同余、剩余系、费马小定理（入门）
- 奇偶性、完全平方数
- 一次不定方程、简单高次不定方程

#### 组合初步

- 加法原理、乘法原理
- 抽屉原理（分割图形、同余类、染色造抽屉）
- 简单计数、逻辑推理
- 极端原理、操作与策略（入门）

#### 代数竞赛技巧

- 对称式、轮换式、主元法
- 余式定理、综合除法（入门）
- 含字母系数方程、根的分布
- 绝对值方程/不等式

#### 几何竞赛拓展

- 梅涅劳斯定理、塞瓦定理
- 托勒密定理、西姆松定理（入门）
- 旋转变换、面积法、构造法
- 四点共圆判定与性质深化

### 1.6 按年级的培优专题索引

参照《数学培优新方法》六模块体系，与苏科版进度大致对应。

#### 七年级（数与式、方程、几何初步）

- 数轴与绝对值深化、不定方程入门
- 整式恒等变形、乘法公式拓展
- 含参方程、应用题建模
- 平行线模型、角计算、初步证明

#### 八年级（因式分解、全等、函数入门）

- 主元法、待定系数法、换元法因式分解
- 分式/根式构造与化简
- 全等辅助线、等腰/直角/中点联想
- 一次函数与几何、坐标法入门

#### 九年级（二次方程/函数、圆、相似、三角函数）

- 求根公式、判别式、韦达定理综合
- 构造方程、整数根、可化二次的方程组
- 二次函数最值、代数最值、抛物线综合
- 旋转变换、圆的性质深化、直线与圆
- 辅助圆、几何最值/定值、三角形四心
- 相似高端模型、锐角三角函数应用
- 梅涅劳斯/塞瓦/托勒密（拓展）

### 1.7 特长生与英才计划常见拔高方向（知识层面）

江苏多地重点高中「学科特长生」「科技/数学特长」及「中学生英才计划」数学方向，选拔侧重学科潜质而非单纯记忆。常见涉及的知识范围：

| 方向 | 典型拔高内容 |
|------|--------------|
| 代数推理 | 恒等变形、构造、整数解、参数讨论 |
| 几何综合 | 辅助线、模型识别、动点与最值 |
| 综合应用 | 阅读理解型新定义、跨章节建模 |
| 竞赛初步 | 简单数论、抽屉原理、组合计数 |
| 逻辑与表达 | 证明书写、分类讨论完整性、反例意识 |

与课内关系：仍以 2022 版课标及苏科版知识体系为根，特长生拔高是在基础上的拓展，而非另起炉灶。

### 2.2 课内同步拔高（对应苏教版）

在教材各章基础上常见的拓展专题。

#### 预备知识与不等式

- 集合划分与覆盖、容斥原理初步
- 充要条件与逻辑综合
- 基本不等式变式、多元均值、配凑技巧
- 一元二次不等式与函数、方程联动

#### 函数

- 抽象函数、复合函数、对称性与周期性
- 指对函数放缩（ln x ≤ x-1，e^x ≥ x+1 等）
- 三角函数：和差/倍角/辅助角、三角不等式、三角模型
- 函数零点、方程根的分布、函数图象综合

#### 平面向量与解三角形

- 向量与几何（重心、内心等）
- 正余弦定理变式、最值与范围
- 解三角形中的面积、周长、多解问题

#### 立体几何

- 空间角与距离（几何法/向量法）
- 截面、外接球/内切球
- 三垂线定理、空间余弦定理
- 折叠问题

#### 解析几何

- 直线系、圆系、曲线系
- 圆锥曲线第二定义、统一定义
- 焦点弦、中点弦、切线/切点弦
- 定点/定值/存在性、面积与最值
- 参数方程、极坐标（拓展）

#### 数列

- 通项求法（累加/累乘/构造/取对数）
- 求和技巧（裂项、错位、分组、放缩）
- 递推数列、周期数列
- 数列与不等式结合

#### 导数

- 含参单调性、极值/最值
- 恒成立与能成立（分离参数、同构、放缩）
- 零点问题、隐零点、端点效应
- 极值点偏移（拓展）
- 导数与数列、不等式联动

#### 概率统计

- 古典概型进阶、条件概率
- 分布列、期望方差
- 回归与独立性检验的综合应用

#### 复数与计数

- 复数几何意义、旋转与最值
- 排列组合模型、二项式定理应用
